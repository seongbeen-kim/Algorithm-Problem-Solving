# Algorithm Problem Solving

## Overview

This repository documents my algorithm problem-solving practice on Codeforces and Programmers.

As an electrical engineering student interested in embedded software and hardware–software integration, I aim to strengthen my C/C++ programming skills, algorithmic thinking, and problem-solving abilities.

This repository also serves as a record of my preparation for technical coding assessments.

## Goals

- Improve C/C++ programming proficiency.
- Develop logical thinking and algorithmic problem-solving skills.
- Strengthen understanding of fundamental data structures and algorithms.
- Prepare for coding assessments in software-related engineering positions.
- Maintain a consistent problem-solving routine.

## Practice Platforms

- [Codeforces](https://codeforces.com/)
- [Programmers](https://school.programmers.co.kr/)

## Weekly Study Plan

**Target: 3–4 problems per week**

- Solve problems regularly on Codeforces and Programmers.
- Focus on implementation and fundamental algorithms.
- Review incorrect solutions and identify improvements.
- Record solutions and important concepts on GitHub.
- Gradually increase problem difficulty.
